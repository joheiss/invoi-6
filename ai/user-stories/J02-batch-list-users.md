# J02 Batch: Benutzer auflisten (`list-users`)

**Epic:** J · **Rolle:** Betreiber

## User Story
Als Betreiber möchte ich alle Firebase-Auth-Benutzer auflisten.

## Akzeptanzkriterien
1. **Gegeben** Benutzer existieren, **wenn** ich `list-users` ausführe, **dann** gibt das Programm die Benutzer (E-Mail, Name, Status) auf der Konsole aus.
