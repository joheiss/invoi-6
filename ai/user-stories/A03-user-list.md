# A03 Benutzerliste ansehen

**Epic:** A · **Rolle:** `sys-admin` · **Route:** `/auth/users`

## User Story
Als Administrator möchte ich alle Benutzer in einer Liste sehen, damit ich sie verwalten kann.

## Akzeptanzkriterien
1. **Gegeben** ich bin als `sys-admin` angemeldet, **wenn** ich in der Sidebar „Benutzer" wähle, **dann** sehe ich die Liste aller Benutzer mit E-Mail, Name, Organisation und Rollen.
2. **Gegeben** ich bin `sys-admin`, **dann** sehe ich die Schaltfläche „Benutzer hinzufügen" und kann einen Benutzer zum Bearbeiten öffnen.
